# 博客改版设计：冷色单栏与五个主题

日期：2026-10-21
范围：公开博客（Hexo 8 + Butterfly 5.5.4），不含 `admin/` 后台界面

## 一、目的与气质

现在的博客干净，但看起来就是一个换了配色的 Butterfly 默认站：首屏 70vh 的空渐变、文章页 400px 的灰色页头、侧栏四张卡片、每篇文章一张同样大小的卡片，没有辨识度。

这次改版的目标是让整个博客读起来像一个人：文艺、小众、感性、冷。这四个词是同一个人身上的同一种气质，不是四种风格，不要拆开分别实现。

这个人的画像（用户认可的版本）：

- 不讨好别人：不求赞赏，不把统计数字摆在显眼处。
- 话少，但每句都挑过：首页只放标题、一句引文和文章目录。
- 有情绪但不外露：感性只藏在一两处细节里（夜空里的北极星、竖排引文），不靠特效。
- 品味前后一致：同一主题内只有一套字体、一种颜色倾向，前后不打架。

判断标准：页面上的每个元素，都问一句"这种人会这么做吗"。

## 二、目标、非目标、反目标

目标

- 首页和文章页按第四节重做，五个主题可切换，每个主题有白天和夜晚两种样子。
- 正文好读：分段正确，行宽约 38 个汉字，衬线正文。
- 现有功能不丢：搜索、评论、留言墙、阅读进度记忆、字号切换、阅读模式、RSS 订阅地址、访客统计。

非目标

- 不改文章内容和标题，不动 `source/_posts/` 里的 Markdown 文件。
- 不重写"关于"页的文字（见第六节待定）。
- 不改后台 `admin/` 的界面，只在第四节第 3 小节要求的地方让后台预览和网站保持一致。
- 不换评论系统，不做 SEO 调整。

反目标（技术上能跑，但出现了就算失败）

- 看起来仍像 Butterfly 模板：侧栏卡片堆叠、卡片阴影、菜单图标、彩色社交图标。
- 加特效：樱花、点击爱心、彩带、看板娘、打字机逐字出现。
- AI 生成页面的常见套路：用"·"把信息串起来、加大字距的小标题、暖奶油底配陶土色强调。
- 首屏因为加载中文字体明显变慢。
- 第一节画像之外的热闹元素：赞赏二维码、品牌色社交图标、"相关文章"推荐墙。

## 三、限制条件

1. **主题是 git 子模块。** `themes/butterfly` 指向上游 `jerryc127/hexo-theme-butterfly`（5.5.4），部署时 `deploy.yml` 用 `submodules: recursive` 重新检出上游代码。直接改子模块里的文件不会被部署。所有改动只能放在：`_config.yml`、`_config.butterfly.yml`、`source/css/`、`source/js/`、`scripts/`（Hexo 扩展 API：filter、injector、helper、generator）。如果实现者认为必须 fork 主题，先停下来问用户，因为需要用户在 GitHub 上建 fork。
2. **部署。** 推送到 `main` 会触发部署（`admin/**` 除外），所以改版在分支上做，用户确认后再合并。
3. **内容只通过后台写入。** 本地仓库只用于代码和主题开发。分段修复必须在渲染阶段处理，不能批量改文章源文件。
4. **后台有 Markdown 预览**（`admin/src/components/editor/markdown-preview.tsx`）。分段规则改了以后，预览要跟着改，否则用户写的时候看到的和网站上不一样。
5. **资源本地托管。** 上一个 PR 把主题资源改成了本地托管（`CDN.third_party_provider: local`），字体也照此处理，不依赖 Google Fonts。中文字体体积大，必须按 unicode-range 切片或做子集，非当前主题的字体不加载。
6. **已有的自定义代码要接着用或替换，不能留成死代码**：`source/css/site-polish.css`（含旧的五套配色）、`source/js/site-accessibility.js`（配色面板、无障碍）、`source/js/reading-tools.js`（字号、阅读进度）、`scripts/*.js`、留言墙（`source/guestbook/`、`source/css/guestbook.css`、`source/js/guestbook*.mjs`、`tools/guestbook*`）。
7. **质量底线**：手机宽度可用、键盘焦点可见、文字对比度达到 WCAG AA、尊重 `prefers-reduced-motion`。
8. 不要动 `.git/config` 和 worktree 指针，知识库的检查脚本会核对它们。

## 四、已定方案

### 1. 全站通用

- **没有顶部导航。** 删除 `menu` 的显示（分类、归档等页面本身保留）。
- **页面入口**：归档、留言墙、关于放在页脚的一行文字链接里。教程、校园、随笔等分类，从文章列表里每篇文章的分类名点进去。
- **回首页**：首页以外的页面左上角放一个小号站名，点击回首页。
- **搜索**：保留本地搜索，入口是右上角一个搜索图标。
- **右下角按钮组**：从上到下是目录（仅文章页）、字号（仅文章页，从正文上方挪过来）、阅读模式、深浅色、换主题，原有的回到顶部和滚动百分比照旧。
- **文字分隔**：信息之间用全角空格或中文逗号分隔，不用"·"。
- **社交图标**：GitHub、哔哩哔哩、Steam，灰色单色。去掉 RSS 图标，但 `atom.xml` 照常生成，`<link rel="alternate">` 自动发现照常保留。
- **引文库**：沿用 `_config.butterfly.yml` 里 `subtitle.sub` 的全部句子，每次加载随机抽一句，去掉打字机效果。

### 2. 首页

布局（冷色主题；小志和稿纸见第 4 小节）：

```
                                                    [搜索]
  Lil Polaris'Booook                        橘  玻
  [GitHub] [哔哩哔哩] [Steam]                子  璃
                                            辉  晴
                                            煌  朗
  ──────────────────────────────────────────────────────
  10.07   随笔-06                                   随笔
  10.04   随笔-05                                   随笔
  09.15   平庸的人生-平淡的博客                     随笔
  ...
  ──────────────────────────────────────────────────────
  归档　留言墙　关于           23 篇文章，554 位访客，1071 次浏览
  © 2025–2026 Lil Polaris          已运行 262 天，10 月 7 日更新
```

- **首屏**：标题 `Lil Polaris'Booook`，约 30px 宋体，左对齐；下方是社交图标；右侧是竖排引文（`writing-mode: vertical-rl`）。首屏高度由内容决定，不再是 70vh。站点副标题"记录教程、校园生活与随笔"不在页面上显示，但仍保留在 `<title>` 和 meta 描述里。
- **竖排引文的断列**：在逗号、顿号、句号处换列，并去掉断开处的那个标点，例如"玻璃晴朗 / 橘子辉煌"。英文句子（如 "There is no place like 127.0.0.1"）改为横排显示。（实现者的决定）
- **文章列表做成目录**：每行三列，依次是日期（MM.DD）、标题、分类名（链接到分类页），行与行之间用细线隔开。不要卡片、阴影和摘要。跨年时插入一行年份。（实现者的决定）
- **置顶文章**：《我为什么要写博客》（`sticky: 1`）保持在第一行，标题后加一个小号灰字"置顶"。（实现者的决定）
- **夜晚的首屏**：底色就是夜空，首屏区域撒约 20 颗很小的星。星星静止，或者闪烁得非常慢，`prefers-reduced-motion` 下完全静止。北极星比其他星稍大稍亮，带一圈很淡的光晕，位置在竖排引文的左上方。
- **页脚**：两行，内容见上图。统计数字的来源：
  - 访客数和浏览量：不蒜子（vercount）的全站 UV、PV。
  - 运行天数：从 `runtime_date: 2026-02-01` 算起。
  - "N 月 N 日更新"：取最新一篇文章的日期。
  - 文章数：生成网站时统计。
- **去掉**：侧栏，包括作者卡、公告卡、分类卡、网站信息卡。

### 3. 文章页

```
  Lil Polaris'Booook                                 [搜索]

        我为什么要写博客
        2026 年 9 月 2 日　随笔　802 字　约 2 分钟　19 次浏览

        正文，单栏居中，每行约 38 个汉字……

                              ✦（分隔线）

        ──────────────────────────────────────────
        标签　博客                                  [分享]
        本文采用 CC BY-NC-SA 4.0 许可
        上一篇 ……                          下一篇 ……
        评论（Utterances）
```

- **页头**：去掉灰色大页头（`top_img`）。标题约 30px 宋体，直接写在页面上。
- **元信息一行**：发表日期、分类、字数、阅读时长、本篇浏览量（不蒜子 page_pv）。教程类文章另外显示更新日期，随笔不显示。
- **正文**：单栏居中，宽度约 38 个汉字，16–17px，行高约 2，段间距约 1.1em。
- **分段**：正文中只隔一个换行的两行，各自成为一段。在渲染阶段（`scripts/` 里的 filter，或 marked 的配置）处理，不改源文件。以下内容不受影响：代码块、行内代码、列表、表格、引用块、HTML 块、数学公式、front-matter。后台预览按同样的规则处理。
  - 背景：随笔大多是一段一行、不空行（如 `why-i-blog.md`、`mediocre-life.md`、`rambling-03/04.md`），现在被 marked 的 `breaks` 渲染成一个带 `<br>` 的大段落。
  - 验收：`why-i-blog.md` 渲染出来是 5 个以上的 `<p>`，而不是 2 个。
- **分隔线**（`<hr>`）：居中一颗小四角星，使用主题强调色，替代 Butterfly 的 `hr_icon`。
- **代码块**：去掉 Mac 风格的三个圆点；保留复制按钮、语言标签、超长折叠；颜色跟随主题。
- **文末**：
  - 第一行：左边是"标签　博客"，最右边是一个分享按钮。点击后，微信、微博、QQ、Facebook、X 五个灰色图标从按钮左侧展开，再点一次收回。点微信时弹出二维码。
  - 第二行：一行小字"本文采用 CC BY-NC-SA 4.0 许可"，带许可证链接，替代原来的版权卡片。
  - 系列文章（如《大学生数字生存指南》）在文末显示一个简短的"本系列"列表。
  - 上一篇/下一篇做成左右两列纯文字，标题太长就截断加省略号。
  - 评论区：保留 Utterances。
- **过期提示**：只对"教程"分类显示。
- **去掉**：侧栏、相关文章、赞赏、正文上方的字号工具条（功能挪进右下角按钮组）、版权卡片。
- **保留**：阅读进度记忆（`reading-tools.js`）。

### 4. 五个主题

"换主题"按钮替换现有的配色面板。每个主题有白天和夜晚两种样子，由深浅色按钮切换；夜晚就是"夜空"。默认主题是"雾"。

冷色三套：只换颜色，字体都用思源宋体（Noto Serif SC），布局相同。

| 主题 | 白天 底 / 字 / 次要 / 强调 | 夜晚 | 夜晚 底 / 字 / 次要 / 强调 / 星 |
|---|---|---|---|
| 雾（默认） | `#eef1f2` / `#252d33` / `#7f8a92` / `#4b687b` | 雾夜 | `#0f1825` / `#d0d8e0` / `#6c7a88` / `#9fb8cc` / `#e4ebf3` |
| 霜 | `#f5f8f9` / `#1d2a31` / `#8597a1` / `#2f7489` | 鸦青夜 | `#121416` / `#c7cbcf` / `#6a7075` / `#a9b1b8` / `#d9dde0` |
| 青瓷 | `#edf2f0` / `#22302b` / `#7b8b85` / `#4a7a6e` | 霜夜 | `#0a1c22` / `#d6e4e8` / `#6a848c` / `#8cc6d4` / `#e8f6fa` |

注意搭配关系：霜的白天配鸦青的夜晚，青瓷的白天配霜的夜晚，这是用户指定的。细线颜色由实现者按底色微调。

**小志**：独立小志（zine）风格，模仿只用两种颜色的孔版印刷。

- 颜色：纸 `#f4f3ef`，蓝色油墨 `#2c4f9e`（次要 `#5b77b8`、`#7f93c4`），向日葵黄 `#ffc52e`。
- 字体：标题和正文用思源宋体；竖排引文、日期、"最近写的"用手写体 Long Cang。
- 首屏：标题分两行（`Lil Polaris'` / `Booook`），约 44px。标题下压着一颗手绘五角星：
  - 星星是黄色填充，用 `mix-blend-mode: multiply` 叠印；
  - 另有一圈蓝色描边，故意错开几像素并略微旋转；
  - 蓝字压在黄星上的地方会叠出绿色。
- 其他细节：
  - 最新一篇文章的日期用黄色手绘圈圈住；
  - 页脚分隔线是手绘波浪线；
  - 整页铺一层约 12% 的纸张颗粒。
- 文章列表上方的标签写"最近写的"，不写"目录"。

**稿纸**：中文绿格稿纸。

- 颜色：纸 `#fcfcf9`，蓝黑墨水 `#22324f`，格线绿 `#79ad93`，浅格线 `#cfe3d8`，次要 `#5f7d70`。
- 首屏网格按 20 格一行：
  - 第一行把 `Lil Polaris'Booook` 一个字符一格写进去；
  - 第二行空着；
  - 第三行起写引文：段首空两格，标点各占一格，写满一行就换行；
  - 遵守避头点：标点落到行首时，挤进上一行最后一格。
- 网格右下方印一行小字"20×20＝400"。
- 格子里的字用毛笔楷书 Ma Shan Zheng，其余文字用思源宋体。
- 社交图标在网格下方左侧。文章列表用浅绿细线分隔。
- 手机上一行 20 格放不下，可以减少每行的格数（实现者的决定），但段首空两格和避头点规则不变。

小志和稿纸在文章页沿用同一套单栏布局，只换颜色、字体和分隔线样式。

字体加载：思源宋体是所有主题共用的；Long Cang 只在小志主题下加载，Ma Shan Zheng 只在稿纸主题下加载。

旧配色迁移：`localStorage` 里旧的 `polaris-palette` 值（mint、rose、blue、lavender、amber）要映射到新主题，避免老读者打开时出错。映射规则由实现者决定，建议 mint→青瓷，其他→雾。

## 五、留给实现者决定的

- 第四节里的布局怎么在不改子模块的前提下实现：用 Hexo 的 filter/injector/helper 改 HTML 输出，还是在 `_config.butterfly.yml` 里关掉相应功能再注入新结构。优先在生成阶段产出正确的 HTML，避免浏览器端用 JS 大面积改 DOM。
- 具体间距、字号阶梯、细线颜色、手机端的适配。
- 首页每页显示的文章数（现在是 10 篇，做成目录后可以多放一些）。
- 中文字体的切片方式和体积预算。首屏不应因字体变慢，可以用 `font-display: swap`。
- Utterances 在各主题和白天/夜晚下用哪个配色。
- 归档、分类、标签、404、留言墙这些页面：套用当前主题的颜色和字体，去掉侧栏；本轮不重新设计布局。留言墙要确认画板和弹幕在五个主题下都看得清。
- 小志和稿纸的夜晚版本，按这个方向先做：
  - 小志：纸换成深靛蓝，油墨换成米白，黄星保留，当作夜里的星；
  - 稿纸：深墨绿底，配浅绿格线和米白字。
  - 做完截图给用户确认。
