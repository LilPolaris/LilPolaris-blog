# 后台检查与优化记录

日期：2026-09-08。基于最新 `origin/main`（`32fa447`），在独立分支
`codex/admin-quality-pass` 中修改。

检查了文章列表、编辑器、媒体库、部署页、设置页及仓库读写实现，并在本机
Mock 环境打开了全部七个管理页面。当前后台已有独立仓库适配器、并发读取与缓存、
SHA 冲突检测、图片与文章原子提交、草稿恢复及 Preview 写入保护，适合继续改进。

## 本轮已完成

| 方面 | 原行为 | 现在的行为 |
| --- | --- | --- |
| 文章复制 | 复制已发布文章会直接在公开文章目录生成副本 | 统一生成草稿，保留正文、未知 front matter 字段和关联资源；清除首次发布时间及自定义永久链接，发布时重新计时 |
| 文章列表 | 状态藏在下拉框，没有筛选重置；更多图标不可点击 | 状态按钮显示数量；搜索覆盖分类；增加清除筛选、空结果操作和可用的更多菜单；显示被折叠的标签数量 |
| 并发交互 | 操作仅依赖下一次 React 渲染禁用按钮 | 增加即时操作锁，避免同一页面重复进入操作；新操作清除旧提示 |
| 编辑目录 | 用正则扫描所有行，代码里的 `#` 也会进入目录 | 使用 CodeMirror 的 Markdown 语法树，忽略代码块并支持下划线标题，保留正确源码位置 |
| 预览目录 | 重复或包含格式的标题可能跳错位置 | 从同一棵渲染树生成目录与唯一 ID，处理重复标题和粗体、链接等内联格式 |
| Mermaid | 改正语法后可能仍显示旧错误；正文改变会重建图表组件 | 新输入使用独立结果状态，忽略过期响应；稳定组件身份，避免无关正文变化触发重画；短暂停顿后渲染 |
| 导航 | 修改正文后，页面内锚点或组合键打开链接也会触发离开确认 | 保留真正离开的保护，跳过页面内锚点和组合键点击 |
| 站点图标 | 浏览器请求 favicon 返回 404 | 增加与后台 LP 标识一致的 SVG 图标 |

预览性能处理遵循 React 对[稳定组件身份与 memo](https://react.dev/reference/react/memo)
的说明；列表搜索使用 [useDeferredValue](https://react.dev/reference/react/useDeferredValue)
降低过滤工作的更新优先级。目录使用 react-markdown 的
[rehype 插件接口](https://github.com/remarkjs/react-markdown)。未做大型文章或真实网络的性能基准，
不将这些改动换算成未经测量的提速百分比。
